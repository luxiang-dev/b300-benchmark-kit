# 局域网与公网映射访问

工作台默认监听 `0.0.0.0:8765`，接受局域网 IP、域名和你自己映射的公网 Host。实际映射、端口转发、DNS、防火墙和 HTTPS 由你配置；程序不自动开放安全组或创建公网隧道。

## 启动与映射

```bash
python3 dashboard.py --host 0.0.0.0 --port 8765 --results /data/server-acceptance/results
```

本机访问 `http://127.0.0.1:8765`；局域网访问 `http://服务器局域网IP:8765`。把公网端口或代理映射到 Ubuntu 的 `8765` 后访问你的公网 URL。`0.0.0.0` 是监听地址，不是浏览器地址。无需 SSH 隧道也能完成配置、启动/停止、监控、日志、报告与证据下载；本地和 SSH 转发方式仍可使用。

映射到域名/端口的根路径 `/`；当前页面和 API 不支持 `/bench/` 等子路径前缀。

TCP 转发通常保留浏览器 Host。HTTP 反向代理也应保留原始 Host；若改写成 `127.0.0.1:8765`，启动时加入实际外部 Origin：

```bash
python3 dashboard.py --host 0.0.0.0 --port 8765 \
  --public-origin https://bench.example.com \
  --results /data/server-acceptance/results
```

将域名换成实际值；非标准端口写入 Origin，如 `https://bench.example.com:19443`，不要加路径或末尾 `/`。可重复指定多个地址。CSRF 校验仍保留，任意 `X-Forwarded-Host` 不会绕过校验。页面能开但启动返回 403 时，检查代理 Host 与 Origin 是否相符。

## 可选认证

页面可以启动真实负载，并下载包含序列号的证据。公网映射端应配置 HTTPS 和身份认证；不要在公网明文 HTTP 上传输 Basic 口令。已有映射端认证时，可以不启用应用认证。

应用的可选口令认证覆盖页面、API、CSRF 会话、日志和报告。在项目/结果目录之外生成私有口令：

```bash
mkdir -p ~/.config/server-acceptance
chmod 700 ~/.config/server-acceptance
python3 - <<'PY'
import os,secrets
from pathlib import Path
path=Path.home()/'.config/server-acceptance/access-token'
fd=os.open(path,os.O_WRONLY|os.O_CREAT|os.O_EXCL,0o600)
with os.fdopen(fd,'w',encoding='ascii') as f:
    f.write(secrets.token_urlsafe(32)+'\n')
print('口令文件已创建；不会覆盖已有文件。')
PY
cat ~/.config/server-acceptance/access-token
```

保存口令后启动：

```bash
python3 dashboard.py --host 0.0.0.0 --port 8765 \
  --access-token-file ~/.config/server-acceptance/access-token \
  --results /data/server-acceptance/results
```

打开 HTTPS 公网 URL 时浏览器弹出登录窗口：用户名 `operator`，密码为文件内容。不要将口令写入 URL、GitHub 或结果目录。服务不打印口令，也不自动签发 HTTPS 证书。

## 地址限制（可选）

`--allowed-host` 可以重复指定允许的 Host，包含浏览器实际使用的端口：

```bash
python3 dashboard.py --host 0.0.0.0 --port 8765 \
  --allowed-host bench.example.com --allowed-host 192.168.1.10:8765 \
  --allowed-host 127.0.0.1:8765 --allowed-host localhost:8765
```

无此参数时，非回环监听接受合法格式的任意 Host。白名单启用后，只接受列出的地址；若代理改写 Host，白名单列入改写后的值，并用 `--public-origin` 指定真实外部 URL。来源 IP 限制由你管理的防火墙/映射端配置。

仅本机使用：`python3 dashboard.py --host 127.0.0.1 --port 8765`。Windows 只读预览可用 `python dashboard.py --preview --host 127.0.0.1`；开放访问不会给预览授予硬件启动权限。
